5. VERIFICATION BY REQUIREMENT AREA
==================================================

5.1 AUTHENTICATION & AUTHORIZATION
- Authentication Model: JWT bearer token in Authorization header.
- Password Security: bcrypt salted hashing (10 rounds).
- Authorization Boundary: Server-side validation on every protected route. Anonymous or unauthorized cross-tenant requests strictly rejected.
- Status: VERIFIED / PASS

5.2 PEOPLE & GUEST MODEL
- Internal People: Name, role, organization, known hourly rate.
- Guests: Name, role, organization, known or explicitly unknown rate.
- Unknown Rate Invariant: Distinguishes unknown rate from zero. Total monetary sums only accumulate known rates; unknown participants are reported via explicit count and notices.
- Status: VERIFIED / PASS

5.3 MEASUREMENT & STATE MACHINE
- Time Authority: Server-authoritative timestamps using measurement_intervals.
- Invariants Enforced:
  - No measurement accumulation before explicit Start.
  - No overlapping intervals for any participant.
  - Pause closes active interval; Resume creates a new interval.
  - Leave terminates participation permanently.
  - End closes all open intervals and freezes calculated cost.
  - Completed meetings do not drift or accumulate over time.
- Status: VERIFIED / PASS

5.4 EXPORTS
- PDF Export: Client-side vector/raster export via jsPDF and html2canvas.
- Image Export: High-resolution PNG receipt generation.
- CSV Export: Server-generated RFC 4180 compliant CSV stream with full session audit metadata.
- Status: VERIFIED / PASS

5.5 VISUAL DESIGN & RESPONSIVENESS
- Tokens: Verified slate canvas, emerald vitality accent, amber hold, and indigo unknown indicators.
- Numeric Precision: JetBrains Mono tabular numbers eliminate layout shift during live ticks.

- Accessibility: Semantic headings, visible focus indicators, accessible contrast, non-color-only state cues, and accessible dialogs.
