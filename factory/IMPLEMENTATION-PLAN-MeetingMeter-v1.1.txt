3. PHASE 1 — DOMAIN AND STATE MODEL
==================================================

Implement/extend:
- PREPARED;
- LIVE;
- ENDED;
- MISSED / NOT HELD representation;
- MANUAL ENTRY provenance;
- RECURRING indicator.

Preserve:
- ACTIVE;
- PAUSED;
- RESUMED;
- LEFT.

Define explicit legal transitions.

Required behavior:
PREPARED -> LIVE -> ENDED

PREPARED -> delete

PREPARED -> reschedule/edit

PREPARED -> MISSED / NOT HELD representation when planned date/time
passes without Start.

Manual Entry is not a live state.

Post-End external-cost editing must not transition ENDED back to LIVE.

==================================================
4. PHASE 2 — DATA MODEL AND MIGRATION
==================================================

Extend persistence for:
- planned date/time;
- meeting duration;
- provenance/type;
- manual-entry reason;
- recurring indicator;
- Last Updated;
- external cost items;
- Cost Library items;
- applied meeting-level external amount;
- participant/external/combined totals;
- reconstructed participation duration.

Preserve existing:
- users;
- people;
- meeting ownership;
- meeting participants;
- measurement intervals.

Migration requirement:
Existing v1.0 records must remain readable and valid.

Do not reinterpret existing completed meetings as Manual Entry or
Prepared unless their stored data explicitly supports that state.

==================================================
5. PHASE 3 — CALCULATION SERVICE
==================================================

Create one authoritative calculation path for:

Participant Cost Total
+
External Cost Total
=
Total Estimated Meeting Cost

Participant calculation:
hourly rate * measured participation duration / 3600

Manual Entry uses explicitly stored reconstructed participation
duration.

Unknown participant cost remains unknown.

External cost:
- EUR;
- zero allowed;
- negative prohibited.

Recalculation must be deterministic.

Post-End external-cost edits recalculate only permitted totals.

==================================================
6. PHASE 4 — PREPARED MEETINGS
==================================================

Implement:
- create/save;
- edit;
- reschedule;
- delete;
- Start.

Guarantees:
- no measurement before Start;
- no cost before Start;
- Last Updated changes on reschedule/edit as required;
- Start produces LIVE state.

When planned date/time passes without Start, support MISSED / NOT HELD
History representation according to the approved Product behavior.

==================================================
7. PHASE 5 — MISSED / NOT HELD
==================================================

Implement History classification for Prepared meetings whose planned
date/time passed without Start.

Ensure:
- no measured time;
- no cost accumulation;
- not equivalent to ENDED zero-cost;
- retain/delete supported;
- can be used as Manual Entry basis.

==================================================
8. PHASE 6 — RECURRING DUPLICATION
==================================================

Implement:
- recurring indicator/tag;
- duplicate operation.

A duplicate must:
- receive an independent meeting id;
- have independent editable configuration;
- not share mutable meeting state with the source occurrence.

Do not implement:
- recurrence scheduler;
- calendar synchronization;
- automatic occurrence generation.

==================================================
9. PHASE 7 — MANUAL ENTRY
==================================================

Implement dedicated Manual Entry creation and edit flow.

Required:
- date;
- duration;
- participants;
- individual participation duration.

Optional:
- time;
- manual-entry reason.

Validation:
0 <= participation <= meeting duration

Allow:
- zero duration;
- participant duration values that do not sum to meeting duration.

Reject:
- negative duration;
- duration greater than meeting duration.

Persist MANUAL ENTRY provenance.

Do not fabricate:
- Start;
- Pause;
- Resume;
- Leave live events.

Manual Entry edits trigger recalculation.

==================================================
10. PHASE 8 — EXTERNAL COSTS
==================================================

Implement meeting external cost collection:
- zero or more items;
- name/description;
- amount;
- EUR.

Validation:
- zero allowed;
- negative prohibited.

Display/persist:
- Participant Cost Total;
- External Cost Total;
- Total Estimated Meeting Cost.

==================================================
11. PHASE 9 — COST LIBRARY
==================================================

Implement user-level Cost Library:
- create;
- view/list;
- update;
- delete/archive as implementation permits.

Library item:
- name;
- default amount;
- EUR.

Selecting a library item copies the default into the meeting.

Meeting override:
- stored independently;
- does not mutate library default;
- remains historically applied to that meeting.

==================================================
12. PHASE 10 — POST-END EXTERNAL-COST EDITING
==================================================

After End:
- allow external-cost edit;
- keep participant measurement locked;
- do not restart meeting;
- do not alter measurement intervals;
- recalculate External Cost Total;
- recalculate combined total;
- update Last Updated;
- update Receipt;
- update History;
- retain ESTIMATED framing.

This is the explicit exception to the v1.0 absolute final-result
immutability rule.

==================================================
13. PHASE 11 — HISTORY / RECEIPT
==================================================

History must represent:
- ENDED;
- MANUAL ENTRY;
- MISSED / NOT HELD;
- RECURRING;
- Last Updated;
- current estimated total.

Receipt must represent:
- standard live result;
- Manual Entry provenance;
- reconstructed participation;
- external costs;
- participant total;
- external total;
- combined total;
- Last Updated where applicable;
- manual-entry reason where supplied.

18. PHASE 16 — BROWSER VERIFICATION
==================================================

Verify these end-to-end flows:

A. PREPARED
Create -> Edit -> Reschedule -> Start -> LIVE -> End

B. MISSED
Create Prepared -> planned time passes -> History MISSED / NOT HELD
-> retain/delete or Manual Entry basis

C. MANUAL ENTRY
Create -> date/time/duration -> participants -> participation ->
save -> History/Receipt -> edit -> recalculate

D. RECURRING
Mark recurring -> duplicate -> edit duplicate -> verify independent
records

E. LIVE COSTS
Configure -> Start -> participant state changes -> End -> Receipt

F. EXTERNAL COSTS
Add multiple items -> verify separate totals -> verify combined total

G. COST LIBRARY
Create library item -> select -> verify copied amount -> override
meeting -> change library default -> verify meeting amount unchanged

H. POST-END
End -> edit external cost -> verify participant measurement locked ->
verify total/Receipt/History/Last Updated change

I. EXPORT
PDF/Image/CSV for applicable result types
