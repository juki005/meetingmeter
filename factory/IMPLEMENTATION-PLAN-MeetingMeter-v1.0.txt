# IMPLEMENTATION-PLAN — MeetingMeter v1.0

## 1. Implementation Principle

Implementation begins in Antigravity only after the Stitch MCP verification gate succeeds.

The implementation must use:

- approved PRODUCT-SPEC v1.0;
- approved DESIGN-SPEC v1.0;

- verified Stitch/Figma design context.

Implement:

- internal people;
- Guests;

Completion:

---

# 6. Phase 4 — Measurement Engine

Implement server-authoritative state transitions:

- Start;
- Active;
- Pause;
- Resume;
- Leave;
- End.

Implement interval-based measurement.

Required invariants:

- no overlapping active intervals for a participant;
- Pause closes active interval;
- Resume creates a new interval;
- Leave closes active interval permanently;
- End closes all remaining active intervals;
- ended meeting cannot accumulate further cost.

---

# 7. Phase 5 — Live Meter

Implement:

- meeting context;
- elapsed meeting time;
- estimated total cost;
- participant states;
- participant actions;
- known/unknown cost presentation;
- explicit End.

The client must reconcile against authoritative server state.

# 12. Phase 10 — Browser Verification

Antigravity must verify actual browser behavior for the core flow:

`CONFIGURE → START → LIVE METER → PAUSE/RESUME/LEAVE → END → FINAL RESULT → HISTORY → EXPORT`

Verify at minimum:

- visible state matches persisted state;
- numerical cost behaves correctly;
- unknown cost remains distinct;
- completed result does not change;
- private history remains protected;
- responsive layout is usable.

---

# 13. Phase 11 — Handoff Completion

AG-HANDOFF may be marked complete for implementation when:

- Stitch verification has been performed;
- retrieved design context has been used;
- discrepancies have been reported/resolved through the appropriate process;
- implementation tasks are executable without guessing;
- technical QA requirements are explicit;
- no unresolved material technical blocker remains.

`PASS` means verification succeeded.

`APPROVED` remains an authorization state and is not implied merely by technical PASS.
