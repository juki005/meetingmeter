## Authority hierarchy

PRODUCT-SPEC = functional/product authority
DESIGN-SPEC = approved textual design authority
TECH-SPEC = technical authority
IMPLEMENTATION-PLAN = implementation sequence
AG-HANDOFF = execution instructions
PROJECT-STATE = current Factory lifecycle state

Stitch/Figma is the implementation-time visual reference.

## Mandatory behavior

Before implementation:

1. Read the current PROJECT-STATE.
2. Read PRODUCT-SPEC, DESIGN-SPEC, TECH-SPEC, IMPLEMENTATION-PLAN and AG-HANDOFF.
3. Verify the current Stitch MCP design gate.
4. Do not invent product functionality from visual designs.
5. Do not silently change approved Product or Design requirements.
6. Report material conflicts instead of resolving them silently.

Implementation must follow the current canonical artifacts.
